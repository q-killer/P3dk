# P3dK // FAB ENGINE (V1.0 - The Pantheon Release)
**Code is Poetry. Computation is Art. PEAK IS PEAK.**
**Live at:** [p3dk.com](https://p3dk.com) (Locked through May 2036)

P3dK is a browser-native, computationally driven CAD and Reality Capture engine. It bridges the gap between raw reality (3D scans/splats) and physical fabrication (3D printing) using WASM-accelerated mathematics and a zero-install CDN architecture. 

## 🧬 Core Philosophy: Product-Led Virality
We do not run ads. The tool must be so undeniably useful, and visually striking, that it sells itself. 
* **The Micro-Brand Boolean:** Generated structures (like classical supports) automatically feature a discreet, 0.5mm recessed `P3dK.com` watermark on the base. When users post their prints online, the geometry acts as our silent marketing team.
* **Zero-Friction Access:** No 2GB installers. No email signups to start. Just click a link, drop an STL, and engineer.

## 🚀 The Pantheon Workbench (Core Tools)
We utilize a Skeuomorphic "Holographic" WebGL interface. Tools are represented by minimalist SVG geometry and interact directly with the 3D canvas via kinematic cursors.
* **The Occam Cleaver:** (Planar Boolean Slicer) *Entities must not be multiplied beyond necessity.*
* **The Vulcan Hammer:** (Planar Decimation) *Snaps chaotic, lumpy scans into flat CAD planes.*
* **The Archimedes Punch:** (Auto-toleranced Joinery) *Bores perfect press-fit alignment pegs.*
* **The Shiva Rasp:** (Destructive Erosion) *Sands away harsh, unprintable 90-degree overhangs.*
* **Indra's Net:** (Magnetic Shrinkwrap) *Wraps chaotic reality-capture point clouds in a watertight, printable mesh.*
* **The Aegis Mask:** (Vertex Exclusion) *Paints safe-zones that generative algorithms cannot touch.*

## 📐 Scientific UI & The Vitruvian Overlay
The interface uses 1-byte Unicode Greek/Scientific symbols (Δ, θ, ⌀, Φ, ε, λ, ρ, Σ) to maintain a microscopic file size while enforcing a premium, high-precision aesthetic. 
* **The Vitruvian Overlay:** Tools like the Archimedes Punch feature active raycast probing. Hovering over a face instantly draws 3D concentric distance rings and projects orthogonal delta (Δ) measurements to adjacent boundaries in real-time.

## 📂 Modular Architecture (The 75kB Promise)
P3dK uses dynamic `import()` modules. The core loads instantly, and heavy WASM/WebGL features are pulled from the CDN only when clicked.
